# Портфолио аналитика 1С

Два учебных кейса по автоматизации процессов торговой компании. Компании, участники, цифры и требования вымышлены. Материалы демонстрируют подход к работе аналитика; интервью и внедрение в реальной организации не проводились.

| Кейс | Проблема | Результат |
| --- | --- | --- |
| [Контроль остатков](01-stock-control/README.md) | Менеджер подтверждает заказ без проверки доступного количества | Правила проверки, постановка доработки и приёмка |
| [Согласование закупок](02-purchase-approval/README.md) | Заявки согласуют в переписке, статусы теряются | Целевой процесс, варианты реализации и приёмка |

## Подход

В каждом кейсе есть описание исходной ситуации, вопросы для обследования, требования, схема процесса, постановка команде разработки, тесты и инструкция пользователю. Неопределённые решения явно помечены как допущения. Документы можно адаптировать к конкретной конфигурации после обследования и проверки типовых возможностей.

## Состав

- `01-stock-control/` — сценарий для торговой компании; ориентиром служит 1С:Управление торговлей. Названия объектов уточняются по версии и настройкам заказчика.
- `02-purchase-approval/` — сценарий для 1С:ERP Управление предприятием. Маршрут согласования здесь проектный пример, не заявление о типовом поведении конкретной редакции.

## Как использовать на собеседовании

Начать с бизнес-проблемы, показать схему «как есть / как будет», объяснить спорные правила и пройти по тестам. Важно отделять согласованные требования от предположений и показывать, что следует проверить в рабочей базе до оценки разработки.

## Ограничения

Репозиторий содержит аналитические артефакты. Код, настройка базы 1С, реальный запуск и пользовательская приёмка не выполнялись. Для внедрения потребуются интервью, доступ к тестовой базе и согласование правил с владельцем процесса.
