# Сценарии приёмки

Тестовые роли: инициатор И1 (цех 1), руководитель Р1 (цех 1), финансовый контролёр Ф1, закупщик З1, посторонний пользователь И2 (цех 2). Суммы условно указаны в рублях; правило НДС и валюты требует согласования.

| ID | Действие | Ожидаемый результат |
| --- | --- | --- |
| T-01 | И1 отправляет заявку без количества или обоснования | Отправка запрещена; указаны незаполненные поля |
| T-02 | И1 отправляет полную заявку на 100 000 ₽ | Статус «На согласовании руководителя», ответственный Р1 |
| T-03 | Р1 согласует заявку ровно на 300 000 ₽ | Статус «Согласована»; заявка доступна З1 |
| T-04 | Р1 согласует заявку на 300 001 ₽ | Статус «На согласовании финансового контролёра», ответственный Ф1 |
| T-05 | Р1 возвращает заявку без комментария, затем с комментарием | Без комментария действие запрещено; с комментарием статус «На доработке», И1 уведомлён |
| T-06 | И1 исправляет возвращённую заявку и отправляет повторно | Новый цикл начинается с Р1; старая история сохранена |
| T-07 | И1 открывает заявку после двух решений | Видит статус, ответственного, время и историю решений |
| T-08 | З1 открывает очередь закупок | Видит согласованные заявки; несогласованную не видит в очереди |
| T-09 | И2 пытается согласовать заявку цеха 1 | Действие недоступно; доступ к данным соответствует согласованным правам |
| T-10 | Построить отчёт за период по двум подразделениям | Количество и суммы по статусам совпадают с контрольным набором заявок |

Дополнительно перед запуском проверить замещение, изменение суммы после согласования и заявки в другой валюте после согласования соответствующих правил.
